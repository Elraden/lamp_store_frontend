# Интерфейс магазина лампочек

Проект выполнен как интерфейс для сайта магазина лампочек по заданию 3. Это React-приложение с каталогом товаров, карточкой товара, корзиной, оформлением заказа и вспомогательными страницами магазина.

## Стек

- React
- React Router
- React Redux
- CSS Modules
- FontAwesome
- Vite

## Страницы

- `/` — каталог товаров с поиском и фильтрацией по категориям.
- `/product/:productId` — карточка выбранного товара с галереей, характеристиками, кнопкой избранного и добавлением в корзину.
- `/cart` — корзина с изменением количества товаров, удалением позиций и итоговой суммой.
- `/checkout` — оформление заказа.
- `/checkout/success` — подтверждение успешного оформления заказа.
- `/favorites` — избранные товары.
- `/sales` — акционные товары.
- `/about` — информация о магазине.
- `/contacts` — контакты магазина и карта.

## Данные

На текущем этапе данные сохранены в виде моков. Основной набор товаров, категории, контакты, бренды и стартовые товары корзины находятся в `src/mocks/catalog.js`.

Состояния интерфейса хранятся в Redux:

- каталог и моковые данные;
- корзина;
- избранное;
- поиск, активная категория, количества товаров и активное изображение в галерее.

## Запуск

Установить зависимости:

```bash
npm install
```

Запустить проект в режиме разработки:

```bash
npm run dev
```

Собрать production-версию:

```bash
npm run build
```
