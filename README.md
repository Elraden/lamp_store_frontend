# Интерфейс магазина лампочек

React-приложение для интернет-магазина лампочек. В проекте есть публичная витрина с каталогом, карточкой товара, корзиной, оформлением заказа и отдельная админ-панель для управления каталогом и продажами.

## Стек

- React
- React Router
- React Redux
- CSS Modules
- FontAwesome
- Vite

## Страницы

- `/` - каталог товаров с поиском и фильтрацией по категориям.
- `/product/:productId` - карточка товара с галереей, характеристиками, избранным и добавлением в корзину.
- `/cart` - корзина с изменением количества товаров, удалением позиций и итоговой суммой.
- `/checkout` - оформление заказа.
- `/checkout/success` - подтверждение успешного оформления заказа.
- `/favorites` - избранные товары.
- `/sales` - акционные товары.
- `/about` - информация о магазине.
- `/contacts` - контакты магазина и карта.
- `/admin` - панель администратора.

## Админ-панель

Админ-панель доступна по маршруту `/admin` и работает через backend API. После входа администратор может управлять данными магазина во вкладках:

- товары: создание, редактирование и удаление товаров;
- дополнительные данные товара: изображения и характеристики;
- категории: создание, редактирование и удаление категорий;
- бренды: создание, редактирование и удаление брендов;
- акции: создание, редактирование и удаление акций, привязка товаров к акциям;
- заказы: просмотр заказов и изменение статуса.

Для авторизации используется админский access token и refresh cookie, которые выдаёт API Gateway.

## Данные и API

Фронтенд получает данные из backend API Gateway. Адрес API задаётся переменной окружения:

```bash
VITE_API_GATEWAY_URL=http://localhost:8000
```

Если переменная не задана, используется значение по умолчанию `http://localhost:8000`.

Основной клиент API находится в `src/api/shopApi.js`. Каталог в Redux нормализует товары, изображения, характеристики, категории и бренды для отображения на витрине.

Моковые данные удалены: при недоступном API каталог остаётся пустым и показывает заглушку с кнопкой повторной загрузки.

## Состояние интерфейса

Состояния интерфейса хранятся в Redux:

- каталог товаров и справочники;
- корзина;
- избранное;
- поиск, активная категория, количества товаров и активное изображение в галерее.

## Запуск

Установить зависимости:

```bash
npm install
```

Запустить проект в режиме разработки:

```bash
npm run dev
```

Собрать production-версию:

```bash
npm run build
```

## Docker

Фронтенд можно собрать и запустить в Docker через `docker-compose.yml`. По умолчанию приложение будет доступно на `http://localhost:5173`, а API Gateway ожидается на `http://localhost:8000`.

Запуск с адресом API по умолчанию:

```bash
docker compose up --build
```

Запуск с явным адресом API Gateway:

```bash
VITE_API_GATEWAY_URL=http://localhost:8000 docker compose up --build
```

На Windows PowerShell переменную можно передать так:

```powershell
$env:VITE_API_GATEWAY_URL="http://localhost:8000"; docker compose up --build
```

Production-сборка выполняется внутри `Dockerfile`, после чего статические файлы раздаются через `nginx.conf`.
